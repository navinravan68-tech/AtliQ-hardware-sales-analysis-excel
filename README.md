# AtliQ Hardware Sales Analysis (Excel)

## Overview
This project analyzes sales performance, profitability, customer growth, and product performance for AtliQ Hardware using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- Pivot Tables

## Reports Included
1. Market Performance Analysis
2. Customer Net Sales Performance
3. Profit & Loss by Fiscal Month
4. Profit & Loss by Fiscal Year
5. Top 10 Products Analysis

## Key Insights

- FY2021 Net Sales reached $598.9M.
- Net Sales grew by 204.5% compared to FY2020.
- India was the highest revenue-generating market.
- Amazon was the top-performing customer.
- AQ Electron 4 3600 Desktop Processor was the best-selling product.
